# 🎮 QuizMaster

QuizMaster este o aplicație realizata in limbajul de programare Java, care are ca scop testarea cunostintelor utilizatorului prin intermediul unui quiz interactiv.

## 🤔 Despre proiect

QuizMaster este o aplicație dezvoltata in limbajul de programare Java, care permite utilizatorilor sa isi testeze cunostintele prin intermediul unui quiz. Proiectul are un scop educational i urmareste dezvoltarea
abilitaților de programare, utilizarea logicii și familiarizarea cu realizarea aplicațiilor interactive.

## 📌 Caracteristici

- ✨ Interfata simplā și ușor de utilizat.
- 🤓 Testarea cunoștintelor prin intrebari.
- 🙌 Afişarea variantelor de răspuns.
- 💻 Verificarea raspunsurilor oferite de utilizator.
- 💯 Calcularea punctajului obținut.
- 😎 Dezvoltat in Java.
